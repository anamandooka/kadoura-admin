Kadoura Admin
=============
لوحة تحكم مطعم قدورة متصلة بـ Supabase.

الملفات:
- index.html: صفحة لوحة التحكم
- app.js: تسجيل الدخول وإدارة الطلبات
- style.css: التصميم
- config.js: إعدادات Supabase

مهم:
ضع هذه الملفات في جذر GitHub Repository، ثم فعّل GitHub Pages من Settings > Pages.
لا تستخدم مفتاح Supabase Secret/Service Role في الواجهة.
